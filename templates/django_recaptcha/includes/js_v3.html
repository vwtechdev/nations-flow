{% comment %} Override do js_v3 do django-recaptcha: o autofill de credenciais do Chrome mobile chama form.submit() nativo, que NÃO dispara o evento 'submit' — o POST ia sem o campo captcha ('Este campo é obrigatório'). Para resolver: 1) Patch de HTMLFormElement.prototype.submit escopado ao form de login: bloqueia submissões sem token (autosubmit), exigindo o toque em "Entrar"; para os demais forms da página repassa ao nativo. 2) Pré-token gerado no load e renovado a cada 90s (o token expira em ~2min): fallback caso o Chrome autosubmeta mesmo assim — o input já tem token válido. 3) Handler de submit: gera o token no clique (grecaptcha.ready) e então submete. Requer FORM_RENDERER='django.forms.renderers.TemplatesSetting' no settings e o widget_v3 renderizando o input ANTES deste include (o script roda com o input já no DOM, e o api.js síncrono garante que window.grecaptcha existe aqui). {% endcomment %}
